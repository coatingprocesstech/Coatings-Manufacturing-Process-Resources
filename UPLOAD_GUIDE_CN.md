# GitHub Upload Guide / GitHub 上传说明

## 目标仓库

Repository name: `Coatings-Manufacturing-Process-Resources`  
Owner: `coatingprocesstech`  
Visibility: Public

## Upload

1. Create the public repository under the `coatingprocesstech` account.
2. Do not initialize it with another README, `.gitignore` or license; the prepared package already contains its own README and catalog.
3. Download and extract `Coatings-Manufacturing-Process-Resources_FINAL_PDF-first.zip`.
4. Upload the **contents inside the extracted folder** to the repository root. `README.md` and `CATALOG.md` should appear directly at the root, not one directory level below.
5. Confirm that GitHub renders the root README and that the `CATALOG.xlsx` download is available.

## Package design

- One resource = one catalog row.
- PDF is the preferred public format.
- PPTX files are not included where a PDF version exists.
- Byte-identical duplicate PDFs have been removed.
- The two editorially arranged paper-explainer video courses are separate from the corresponding journal papers and cross-linked.
- The five journal-issued paper PDFs are preserved unchanged.
