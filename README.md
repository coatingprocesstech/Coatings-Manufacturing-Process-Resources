# Coatings Manufacturing Process Technology

## 涂料制造工艺技术 · Public Technical Resource Library

A curated collection of public lectures, conference presentations, journal-arranged paper-explainer video courses, published papers and engineering resources by **Yi Teng (滕毅)**.

本资料库整理滕毅在涂料制造领域的公开课程、会议演讲、期刊编辑部安排的论文讲解视频课、正式发表论文及工程工具。

**The source materials are mainly in Chinese.** Each resource has an English title, concise English overview and searchable technical keywords. These are discovery summaries, not full translations.

**原始资料主要为中文。** 每项资料提供英文标题、英文简介和技术关键词，方便国际同行检索；不代表全文翻译。

## Organization principle / 资料组织原则

One resource = one catalog row. Multiple file formats do not create multiple resource records. This public package prioritizes PDF. Where both PPTX and PDF existed, only the PDF reading version is included.

一项资料对应一个资源编号和一条目录记录。PPTX 与 PDF 是同一资料的不同格式，不重复建立资源。本版优先公开 PDF；同时有 PPTX 和 PDF 时，只收录 PDF 阅读版。

The two paper-explainer video-course decks are separate from their related journal papers, with direct links between each pair.

两份论文讲解视频课件与对应的期刊论文分别归档，并建立相互链接。
